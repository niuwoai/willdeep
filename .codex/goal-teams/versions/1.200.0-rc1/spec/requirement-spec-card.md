# Requirement Specification Card：专家圆桌准备室与真流式发言

> 目标版本：1.200.0-rc1  
> 状态：产品规格初稿  
> Owner：产品-议题准备流程规格  
> 来源：用户确认方案、现有 `AgentRoundtable` 状态机与界面、历史设计稿

## 1. 目标与用户价值

把专家圆桌从“输入一句话后直接开讲”升级为一场有准备、有选择权、过程可感知的讨论：

- 正式讨论前，AI 先帮助用户把模糊议题细化成可讨论的问题与框架。
- AI 根据议题给出专家阵容建议和逐位推荐理由，用户可在 2～6 人范围内增删。
- 用户必须明确确认议题、框架和阵容，专家才能进入开场与讨论。
- 专家正文逐字流式出现；正文结束后再分析立场、建议与风险，不让结构化输出阻塞阅读。
- 准备、讨论、错误与恢复状态均可理解、可重试、可从历史会话继续。

## 2. 核心功能

| 能力 | 必须满足 |
| --- | --- |
| 议题细化 | 保留用户原始议题；AI 给出精炼标题、核心问题、3～5 个讨论维度和 1～3 个高价值澄清问题。 |
| 继续对话 | 用户可以用约 3 行的输入区补充背景、纠正假设或要求重拟框架；每轮修改都清楚标记为“建议稿”，不冒充用户已确认。 |
| 框架确认 | 框架卡片可逐项阅读；用户可继续修改，也可进入专家选择。 |
| 专家推荐 | 默认推荐 3～4 位，每位显示姓名、专业身份、头像、擅长视角和针对本议题的推荐理由。 |
| 阵容增删 | 完整专家池可浏览；最少 2 位、最多 6 位。推荐项默认选中，增删后即时显示人数与约束。 |
| 明确门禁 | 只有“确认框架与 N 位专家，开始讨论”按钮可启动讨论；打开页面、按 Enter、接受某个澄清答案均不得暗中开会。 |
| 真流式发言 | 当前专家正文随模型增量逐字显示，并展示“正在发言”；结束后固定正文，再显示“正在分析立场”，结构化失败不得丢正文。 |
| 状态可视化 | 支持、反对、中立、待定必须同时用文字、图标和颜色表达；右侧态势看板跟随已完成发言更新。 |
| 恢复与兼容 | 准备中、选人中、发言中、等待用户、失败状态可恢复；不含新增字段的旧会话继续打开并沿用原有讨论/文档路径。 |

## 3. 用户主流程

1. 用户在圆桌首页输入议题，按 Enter 或“发起讨论”。
2. 系统创建持久化圆桌会话并进入“准备室”，不启动专家讨论。
3. AI 展示精炼议题、讨论框架、澄清问题和初步专家建议。
4. 用户回答问题、补充背景或要求修改；AI 更新建议稿。
5. 用户确认框架，进入专家阵容选择。
6. 系统预选推荐的 3～4 位专家；用户可在专家池中增删至 2～6 位。
7. 用户明确点击开始按钮；系统锁定本轮议题、框架与阵容，进入开场。
8. 专家逐位真流式发言；完成后后台提取立场与建议，态势看板更新。
9. 若专家追问，用户可在三行输入区回答、点选快捷答案或引用发言/划词引用。
10. 讨论收敛后生成并自动保存结论文档；用户可继续讨论或导出。

## 4. 关键边界

- “按 Enter”在首页仅进入准备室；在准备室输入区用于提交补充，在多行编辑时 `Shift+Enter` 换行。
- 不能用倒计时、默认按钮焦点或 AI 自行判断代替用户的开始确认。
- 少于 2 位时开始按钮禁用并解释原因；达到 6 位后未选专家的添加操作禁用。
- 用户修订框架后，旧推荐可保留为候选，但必须重新评估并标注推荐理由是否已更新。
- 流式草稿不是正式消息；完成后原子替换为正式消息。取消、失败或重启不得生成重复发言。
- 不逐 token 持久化；允许节流 UI 更新和低频检查点，正式正文完成时必须持久化。
- 旧会话不强制倒退到准备室；历史 `opening/discussing/awaitingUser/completed` 按原阶段恢复。

## 5. 非目标

- 本版不支持用户创建自定义专家人格或上传专家头像。
- 本版不支持同一位专家并行输出多个发言。
- 本版不将圆桌专家替换为真实人类专家，也不提供法律、医疗或投资结论保证。
- 本版不重做最终 Markdown 文档的导出格式，只保证新增流程不破坏既有保存与渲染。
- 本版不让用户自由配置无上限专家数量、模型参数或每轮预算。

## 6. 可验证结果

- 新议题提交后可观察到准备室，且在明确点击开始前没有专家开场或正文请求。
- AI 建议稿包含核心问题、3～5 个框架维度、1～3 个澄清问题及带理由的专家建议。
- 专家选择的 2 人下限与 6 人上限在 UI 和业务层同时生效。
- 发言过程中至少观察到多个正文增量，完成后正文与最终消息一致；结构化失败时正文仍存在。
- 准备、选人、发言、取消、失败、重试与应用重启路径不会越过确认门禁或重复消息。
- 旧圆桌 fixture 可解码、打开并继续原有路径；新增用户文案有中英文资源且不只靠颜色表达状态。

## 7. 已确认默认值

- 推荐阵容：3～4 位。
- 可选阵容：最少 2 位，最多 6 位。
- 新增专家：法律合规、数据研究、市场增长、组织运营。
- 既有心理专家保留原始标识，展示定位升级为行为心理与决策。
- 流式方案：正文自由文本真流式，完成后进行第二次轻量结构化分析。
