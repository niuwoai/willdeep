# Reflection

Build the reflection only from information available in the current conversation, user-provided files, and approved workspace evidence.

## Workflow

1. Clarify the period and desired tone.
2. Gather the relevant visible evidence without reading unrelated private files.
3. Separate events, feelings, decisions, lessons, and next steps.
4. Mark uncertainty and do not invent conversations, emotions, or activities.
5. Write in the user's requested voice and language.
6. Save a durable lesson with `add_memory` only when the user asks or clearly establishes a future-facing rule.
7. Create or update a journal file only when the user requests a file and provides an approved workspace location.

Do not run automatically at night, impersonate a persistent personality, inspect hidden chat logs, or mutate identity and emotion files.
