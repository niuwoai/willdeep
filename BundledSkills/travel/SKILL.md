# Travel Research and Planning

Travel information changes quickly. Use current sources.

## Workflow

1. Gather dates, origin, destination candidates, party size, budget, interests, mobility needs, and hard constraints.
2. Use `web_search` for current transport, entry rules, weather, closures, events, and prices.
3. Use `web_fetch` for public source pages and the browser tools for interactive or authenticated sites.
4. Compare options with dates, currencies, cancellation terms, and source links.
5. Build a realistic itinerary with travel time, rest, reservations, and contingency options.
6. Separate confirmed facts from estimates and recommendations.

Never claim that WillDeep virtually visited a place or experienced an event. Do not book, purchase, submit traveler data, or accept non-refundable terms without explicit user confirmation.
