# 截图说明

- **来源**：本机安装的 `/Applications/WillDeep.app`，版本 **1.375.0-rc3**，macOS 25.6（Darwin 25.6.0）。
- **拍摄方式**：按窗口捕获（`screencapture -l <window>`），Retina 原始分辨率，未缩放。
- **脱敏**：涉及账号、余额、服务器地址、私人会话标题的区域一律高斯模糊或裁掉。API Key 在界面上本身就是掩码显示，不额外处理。
- **界面差异**：模型列表、插件、技能和集成项会随账号权限与安装情况变化，你看到的界面可能与截图不同。
