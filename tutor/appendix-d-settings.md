# 附录 D 设置项速查

**⌘,** 打开设置窗口。左边是十一个分组，有的分组里还有页签（顶部的分段选择器）。这份表用来"我记得有个开关，但忘了在哪"。

## D.1 全景

| 分组 | 页签 | 主要内容 |
|---|---|---|
| 账户与设备 | some.im、手机网关 | 登录、积分、默认模型模式、图片/视频模型、手机接入；**应用语言也在这一组的底部** |
| AI Agents | AI 服务商、通知、记忆、规则 | 服务商与 Key、路由档位、辅助模型、并发、通知与 Webhook、记忆、全局规则 |
| 本地模型 | — | Ollama 等本地服务的接入与"先用本地"开关 |
| 代理档案 | — | 子 Agent 工种与调度台执行器的模型、职责、工具与预算 |
| Agent 工具 | 技能、MCP、工具、密钥管理器 | 技能与市场、MCP 服务器与信任级别、永久允许列表、CLI 安装、Computer Use 权限、密钥 |
| 运行时 | 本机 Agent、运行时 | 外部 CLI 发现、SSH / Daemon 远端工作区 |
| 集成 | 连接器 | 飞书、钉钉、企业微信、Replicate |
| 终端 | — | Shell、字体、字号、光标、配色、环境变量 |
| 桌面宠物 | — | 开关与形象 |
| Agent 外观 | — | 壁纸、聊天字号行高、字体平滑、先写设计再写代码 |
| 更新 | 更新、Privacy、诊断导出 | 自动更新、产品分析、诊断包导出 |

## D.2 常用项与默认值

### 模型相关（AI Agents → AI 服务商）

| 项 | 默认 | 说明 |
|---|---|---|
| 路由默认档位 | Auto | Auto / Flash / Pro |
| 每个服务商的并发上限 | 3 | 范围 1–8，按服务商独立计 |
| Anthropic 回复上限 | 32768 | 范围 1024–128000 |
| 对话标题模型 | 空（用 Flash） | 建议指一个便宜模型 |
| 上下文压缩模型 | 空（用 Flash） | 挑窗口大的，别用推理模型 |
| Web 搜索服务 | 自动 | Exa → Brave → some.im 托管 |
| 自动归档较旧会话 | 关 | 开启后按项目保留最近 N 个 |

### 记忆（AI Agents → 记忆）

| 项 | 默认 |
|---|---|
| 启用记忆 | 开 |
| 自动检索记忆 | 开 |
| 单次最多检索条数 | 5（1–20） |
| 相似度阈值 | 0.10 |
| 自动归纳对话 | 开 |
| 每日记忆维护 | 开，03:00 |
| 临时记忆 TTL / 归档保留期 | 各 30 天 |
| Embedding 模型 | `text-embedding-3-small` |

### 技能（Agent 工具 → 技能）

| 项 | 默认 |
|---|---|
| 从对话中自动提取可复用技能 | 开 |
| 最少工具调用数 | 6（1–50） |
| 用户技能目录 | `~/.willdeep/skills/<名字>/SKILL.md` |

### MCP（Agent 工具 → MCP）

| 项 | 默认 |
|---|---|
| 传输方式 | stdio 或 streamable-http |
| 超时 | 30 秒（1–180） |
| 信任级别 | 默认（只读自动、写入询问） |

### Agent 外观

| 项 | 默认 | 范围 |
|---|---|---|
| 聊天字体 | PingFang SC | |
| 文字大小 | 14 pt | 11–20 pt |
| 行高 | 1.20× | 1.2–2.0，步长 0.05 |
| 壁纸图片大小上限 | — | 小于 64 MB、像素总量不超过 8000 万 |

字号只影响对话正文和 Markdown 块。工具卡摘要、底栏、消息头、输入框工具栏保持固定字号，这个旋钮不缩放整个界面。

### 终端

| 项 | 默认 / 范围 |
|---|---|
| Shell | `/bin/zsh`（可自由填） |
| 字号 | 10–20 |
| 配色方案 | 跟随应用皮肤，另有十余套可选 |

### 语言（账户与设备组底部）

可选：跟随系统、简体中文、English、日本語、Español、Français。

**改完必须重启 App 才生效**，界面会弹窗问你要不要"立即重启"，并常驻一条橙色提示。没翻译到的文案会回退成英文。

### 更新

| 项 | 默认 |
|---|---|
| 自动下载并安装更新 | 开（直接绑 Sparkle 自身的偏好） |
| 检查间隔 | 1 小时 |
| 安装前验证 | 强制（Ed25519 签名） |

### Privacy（产品分析）

默认参与，可随时关。关掉后不再采集，本地队列也会清空。

**会上报**：App 版本、macOS 主版本、CPU 架构、界面语言、每次请求的服务商与模型、是否成功、耗时、Token 数、结构化错误码、功能使用次数。

**不上报**：你的提问和模型回复、文件名与路径、文件内容、终端命令与输出、截图、剪贴板、API Key、邮箱昵称、原始错误正文、硬件标识。

匿名标识是本机随机生成的，可以重置；也可以一键删除这台设备上报过的全部数据。

## D.3 凭据都存在哪

| 内容 | 位置 |
|---|---|
| 服务商 API Key、搜索 Key、图像理解 Key | macOS 钥匙串 |
| 密钥管理器里的机密 | macOS 钥匙串，模型只看到 `${secret:别名}` 占位符 |
| MCP、技能、连接器的凭据 | macOS 钥匙串 |
| 远端 Daemon token | macOS 钥匙串 |
| SSH 私钥 | **不存**，只存你填的那个路径 |
| 服务商地址、模型名、显示名等非敏感配置 | `~/Library/Preferences/com.willdeep.app.plist` |

## D.4 几个藏得比较深的入口

| 我想找 | 在哪 |
|---|---|
| 应用语言 | 设置 → 账户与设备，页面最下面 |
| 永久允许列表（清理"始终允许"） | 设置 → Agent 工具 → 工具 |
| Computer Use 的两个系统权限 | 设置 → Agent 工具 → 工具 |
| 安装 `willdeep` 命令行工具 | 设置 → Agent 工具 → 工具 |
| 诊断包导出 | 设置 → 更新 → 诊断导出 |
| 全局规则文件 | 设置 → AI Agents → 规则 |
| 插件中心 | **不在设置里**，在侧边栏 |
| 沙箱开关 | **不在设置里**，在输入框的"更多设置" |
