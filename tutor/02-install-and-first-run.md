# 第 2 章 安装、升级与首次启动

这一章的目标：把 WillDeep 装上、跑起来、确认版本，并且知道以后怎么更新。

## 2.1 安装

1. 打开 <https://willdeep.com>，下载 macOS 版 DMG。
2. 双击 DMG，把 `WillDeep.app` 拖进「应用程序」。
3. 第一次打开时，如果系统提示来自身份不明的开发者，说明你下到的不是官方公证包，请重新从官网下载。官方发布的 DMG 经过 Developer ID 签名和 Apple 公证，正常情况下双击即可打开。

系统要求是 macOS 13.7 及以上。预发布（rc）版本有时只编译 Apple Silicon 架构，Intel 机器请使用正式版本。

如果你想从源码构建，仓库根目录的 `docs/DEVELOPMENT.md` 有完整步骤；本手册按官方安装包描述界面。

## 2.2 第一次启动会要哪些权限

WillDeep 不会在启动时把所有权限一次性要过来，而是在你真正用到某个能力时才申请。常见的几项：

| 权限 | 什么时候会问 | 不给会怎样 |
|---|---|---|
| 文件与文件夹访问 | 第一次选择工作区目录时 | Agent 读不到项目文件 |
| 通知 | 第一次有后台任务完成时 | 任务跑完不会提醒你 |
| 屏幕录制 | 用到截图、网页面板抓图时 | 相关工具报错 |
| 辅助功能 | 用到操作其他 App 的能力时 | 无法控制别的应用 |
| 麦克风 | 用语音输入时 | 语音输入不可用 |

这些开关都在「系统设置 → 隐私与安全性」里，事后也能改。给权限的原则和别的 App 一样：用到再给，不用就撤。

有一条容易困惑的地方：**操作其他 App 的能力（Computer Use）用的是一个独立签名的辅助程序**，辅助功能和屏幕录制这两项要授权给它，授权 WillDeep 主程序并不等于授权了它。「设置 → Agent 工具 → 工具」里有这两项的状态和申请按钮，从那里申请最省事。这套能力不会录制或保存系统音频。

## 2.3 确认版本

菜单栏「WillDeep → 关于 WillDeep」会显示当前版本号，例如 `1.375.0-rc3`。

![关于 WillDeep](assets/about-window.png)

带 `-rc` 后缀的是预发布版本，功能比正式版新，也更可能带着没修完的问题。手册和界面对不上时，先比一下这个版本号。

## 2.4 自动更新

WillDeep 用 Sparkle 做更新：检查 → 下载 → 验签 → 退出 → 替换 → 重启，全程不需要你手动拖动应用包。

- App 启动时会在后台检查一次。
- 想立刻检查：「设置 → 更新」里有手动检查入口。
- 更新包必须通过 Ed25519 签名验证才会被安装，签名不对会直接失败而不是装上一个坏包。
- 更新说明只显示本次发布的变化，不是整份变更日志。

有一件事值得知道：官网下载链接背后有 CDN 缓存，刚发版的头几分钟，直接点下载拿到的可能还是上一版。走 App 内的更新流程不受这个影响。

## 2.5 数据放在哪

日常不用关心，排错和迁移时有用（完整清单见[附录 C](appendix-c-paths.md)）：

- 会话、定时任务、插件数据、媒体产物：`~/Library/Application Support/WillDeep/`
- 应用偏好：`~/Library/Preferences/com.willdeep.app.plist`
- 日志：`~/Library/Logs/WillDeep/`
- API Key 等凭据：macOS 钥匙串，不存在上面这些文件里

换机器时，把 `~/Library/Application Support/WillDeep/` 整个复制过去，会话和定时任务都在；凭据需要在新机器上重新登录或重新填。

## 2.6 卸载

1. 退出 WillDeep。
2. 删除 `/Applications/WillDeep.app`。
3. 如果确定不再用，删除 `~/Library/Application Support/WillDeep/` 和 `~/Library/Preferences/com.willdeep.app.plist`。这一步会连同所有历史会话一起删掉，删之前先确认没有需要留的记录。

如果你之前装过多个版本、Finder 的「打开方式」里出现一堆重复的 WillDeep，那是历史副本仍然存在于磁盘上被系统登记了。把旧副本删掉，或者用 `lsregister -u` 逐个注销即可，不要用会重置所有默认关联的 `-kill` 参数。
