# 第 9 章 工作面板：文件、预览、终端、浏览器

右栏叫"工作面板"。它不是装饰，Agent 干活时的大部分现场都在这里：文件树是它眼里的项目，终端是它敲命令的地方，浏览器是它看网页的窗口。你在这里看到什么，它大致也在看什么。

本章讲四个日常面板，Diff（审阅）单独放[第 10 章](10-review-and-commit.md)，媒体相关的放[第 12 章](12-media-and-workshops.md)。

## 9.1 打开与整理

三种打开方式：

1. 会话标题行右边的图标条，点一下开、再点一下关。
2. 标签条上的 ➕ 菜单：新建本地 Shell、连已配置的 SSH 主机、开浏览器，以及其余面板。
3. Agent 自己打开。它开终端时终端面板会自动弹出来，产出网页组件时"网页组件"面板会自动弹出来。聊天里点一个文件名，已改动的会跳去"审阅"并定位到那个文件，没改动的跳去"预览"。

标签可以拖动排序，也可以**拖出窗口**变成独立窗口。分离之后终端进程、网页状态都原样保留，不会重启。要收回来，点标签条右边的网格按钮，在概览里选"收回侧栏"，或者"收回所有窗口"一次性收齐。

面板底部那句提示值得记住：**关闭标签不会停止正在运行的终端或任务**。关掉只是收起界面，进程还在。

有两个面板需要先装技能包才会出现：Dev Server 需要"Web 编程"，短剧需要"短剧制作"。技能包一旦在本次会话里介入过，本会话内就不能再关掉它。

## 9.2 文件面板

显示当前会话工作区的文件树，目录是懒加载的，展开时才读盘。每行带 Git 状态标记，改过哪些文件一眼能看到。

- **单击**选中。如果点的是 Markdown 或 HTML，面板会自动切到"预览"把它渲染出来。
- **双击**在 Finder 里显示。
- **右键**有新建文件、新建文件夹、在终端中打开、在 Finder 中显示、复制路径、复制相对路径；文件还多一个"在编辑器中打开"。

这里有个要说清楚的点：**"在编辑器中打开"是交给系统默认应用打开**，不是 WillDeep 内置的编辑器（这一版没有内置编辑器）。二进制文件则会改成在 Finder 里显示。

面板里没有搜索框。要按名字找文件，用输入框的 `@` 引用，打几个字符就能筛。

没绑工作区时，面板会告诉你"本会话未选择工作区"，并给一个"选择工作区"按钮。它同时会提醒你：聊天、终端、浏览器和预览不需要工作区也能用。

## 9.3 预览面板

只读渲染，支持两类文件：

- **Markdown 和 HTML** —— 渲染出来看，排版跟随你在设置里选的聊天字体、字号和行高。
- **其它文本** —— 等宽原样显示，可以选中复制。

工具栏上有个文件夹按钮"选择文件…"，可以直接挑一个文件来看。默认会尝试打开工作区的 README。

写文档、写周报、让 Agent 生成 Markdown 报告时，预览面板是最顺手的验收方式：让它写，你在右边看渲染效果。

## 9.4 终端面板

这是一个**真正的终端**，不是命令输出的展示区。多标签，每个标签是一个完整的终端会话。

**顶部状态条**告诉你三件事：

- 这个标签是什么类型：本地 Shell / SSH / 委托 Shell
- 当前状态：启动中 / Shell 就绪 / 运行中 / 前台任务运行中 / 交互程序 / 已退出
- 一组控制按钮：中断当前程序（Ctrl-C）、发送 EOF（Ctrl-D）、Telnet 退出键（Ctrl-]）、停止会话

**连远端**：先在「设置 → 运行时」里配好 SSH 主机（[第 15 章](15-remote-runtimes.md)），然后从 ➕ 菜单的"已配置的 SSH 主机"里新建标签。

有个安全提醒是内置的：本地标签里你可能手工 `ssh` 到了别的机器，界面会提示"执行远程操作前，请检查提示符或运行 hostname 确认主机"。状态条上还有个"提取主机标识"按钮，点一下会去问当前 shell 的主机名、IP 和系统，并把标签名改成主机名。开五六个标签同时连不同服务器时，这个功能能救命。

**终端捷径（录制回放）** 是这个面板的特色：

1. 点"开始录制"，然后正常敲你的命令。
2. 点"停止录制"，这一串命令被存成一条捷径。
3. 以后在"最近捷径"里点一下就能重放，也可以编辑、克隆、改名、删除。

捷径里如果需要密码，它会存成**密码占位**，执行到那一步时提示你填，而且只在终端关闭回显时执行。填进去的密码只保存在这台 Mac 的加密保险库里，不会发给模型。捷径的 JSON 里保存的也只是密钥引用，不是密钥本身。

捷径编辑器是一个独立窗口，⌘S 保存。

## 9.5 浏览器面板

内置的浏览器。工具栏是标准那一套：后退、前进、刷新、地址栏、前往，另外有"导入 Chrome"和"截图"。

它故意**不需要技能包**就能用——聊天里出现一个局域网地址，你想点开看看，这就是普通的浏览。受技能包管的是 Agent 的浏览器工具（截图、点击、填表、操作 Chrome 标签页），那才是需要授权的能力。

典型用法：让 Agent 改前端，改完在这个面板里打开本地地址自己看效果，再让它继续调。

## 9.6 网页组件面板

Agent 有一个"展示组件"的工具，能生成一小段 HTML 或 SVG 直接渲染出来——图表、表格、对比卡片这类。生成的组件会同时出现在对话里和这个面板里，面板里能按会话集中翻看。

组件跑在一个严格的沙箱里：没有网络、不能导航、不能访问文件、外部脚本和样式都被拦。所以你看到的组件一定是自包含的。组件上的按钮也不能直接执行工具，它只能把你的意图交回给 Agent，由 Agent 走正常的审批流程。

## 9.7 Dev Server 面板

需要"Web 编程"技能包。它把当前工作区的前端、后端和 `tail -f` 日志任务集中在一个列表里：

- **项目命令**：自动扫描工作区里的启动脚本；扫不到时可以点"让 AI 识别"。
- **Tail 日志**：选一个日志开始跟。
- **运行中 / 最近**：每条都能启动、重启、停止、读取输出。

Agent 启的后台任务和你在这里手动启的会出现在同一个列表里，不用两边找。

## 9.8 后台任务面板

严格说它属于多 Agent 那一章（[第 11 章](11-multi-agent.md)），但位置在这里，顺带提一下：它列出所有后台进程，可以按当前会话或全部会话筛，可以搜索、看 PID 和工作目录、复制命令、复制输出、停止任务，日志可以双栏或标签页布局，输出能按 stdout / stderr 分流。

跑了个东西不知道它有没有停，来这里看。
