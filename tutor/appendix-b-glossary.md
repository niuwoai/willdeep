# 附录 B 术语表

界面里出现的词，按你大概会遇到的先后顺序排。括号里是英文或代码里的叫法，方便你搜仓库。

## 基础

**会话（Chat / Session）**
一次任务的完整记录。左侧边栏一行就是一个会话。关掉 App 不丢。

**工作区（Workspace）**
这次会话允许读写的目录范围。没选工作区时只能聊天，动不了文件。

**项目（Project）**
一组会话共享的目录归属。把会话绑到同一个目录，它们会归到同一个项目下。

**运行位置（Runtime）**
命令实际执行的地方：本机、SSH 主机，或远端的 `willdeep-agent` daemon。

**工具（Tool）**
Agent 能调用的动作，比如读文件、写文件、跑命令、抓网页、生成图片。每次调用在会话里都有一张工具卡。

**交付物（Artifact）**
任务留下的可验证结果：代码改动、测试输出、图片、报告。

## 模型与成本

**服务商（Provider）**
模型的来源，例如 some.im、OpenAI、Anthropic、本机 Ollama。一个服务商下面有多个模型。

**省心托管（Managed routing）**
用 some.im 的托管服务，不用自己配 Key，由服务端按任务挑模型。

**BYOK**
Bring Your Own Key，用自己的 API Key 直连服务商。

**上下文窗口（Context window）**
模型一次能看到的最大 token 数。输入区旁边的百分比就是当前占用。

**压缩（Compaction）**
上下文快满时，把前面的对话摘要化，腾出空间继续跑。压缩会损失细节。

## 执行与安全

**审批模式（Approval mode）**
Agent 动手前要不要问你，有几档松紧不同的策略。

**智能审核（Smart approval）**
默认档位。低风险动作自动放行，风险动作交给你确认，中间由一个"裁判"模型判定。

**沙箱（Sandbox）**
限制工具执行范围的机制：写入只允许在工作区内，敏感环境变量被剥离，凭据路径读取被内核级拒绝。

**工作区边界（Workspace path guard）**
判断一个路径能不能写的那道关。软链接不算第二扇门——要多一个目录，就明确把它加进工作区。

**升档（Escalation）**
某次执行需要超出当前沙箱档位的权限时，向你申请提权。

**审计日志**
`judge.jsonl` 记裁判判定，`sandbox.jsonl` 记每次执行用了哪一档沙箱。位置见[附录 C](appendix-c-paths.md)。

## 任务组织

**普通模式**
默认模式。Agent 按需自己规划再执行，需要规划时以计划卡呈现。早期版本里独立的"计划模式"已经并进这里，界面上不再单列。

**目标模式（Goal）**
长任务用的模式：写下目标陈述和验收清单，Agent 持续对照这份清单推进，可以暂停和继续。会话没绑工作区时这一项不可选。

**计划卡**
Agent 上报任务步骤与进度的卡片。可以展开、编辑步骤、插入步骤、从某一步重启，也可以要求它重新规划。

**子 Agent / 后台 Worker（Subagent / Worker）**
被派去做子任务的另一个 Agent。主会话可以继续对话，Worker 在后台跑。

**代理档案（Agent profile）**
给不同职责（调查、实现、修构建、审查）预设的模型与工具权限组合。

**调度台（Dispatch board）**
多个任务节点的看板视图，显示哪些在跑、哪些完成、哪些卡住。

**专家圆桌（Roundtable）**
让多个角色就同一个问题各自发言再汇总的讨论形式，产出一份文档。

## 扩展

**Skill（技能）**
一包写好的做事说明，用 `$` 在输入框里挂载，让 Agent 按既定流程做某类任务。

**MCP（Model Context Protocol）**
接外部工具的标准协议。接上之后，外部系统的能力就变成 Agent 可调用的工具。

**插件（Plugin）**
装进 WillDeep 的独立页面或服务，在侧边栏里出现，比如待办、收藏夹、工坊和内置游戏。

**外部执行器（External executor / ACP）**
把任务交给 Codex CLI、Claude Code 这类已有工具来执行，WillDeep 负责调度和展示。

## 其他

**定时任务（Scheduled task / Routine）**
按 cron 或固定间隔自动跑的任务，有独立的运行历史。

**媒体任务（Media task）**
生成图片、视频、音频的异步任务，在"媒体任务"面板里看进度和产物。

**桌面宠物**
窗口里那只会动的小家伙，可以在设置里关掉。
