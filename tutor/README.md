# WillDeep for macOS 使用手册

> 适用版本：**1.375.0-rc3**（macOS 13.7 及以上）
> 写作日期：2026-09-15
> 截图来源：本机安装的 `/Applications/WillDeep.app`，版本与上面一致。涉及账号、余额、服务器地址、私人会话标题的部分已裁切或打码，详见 [截图说明](assets/README.md)。
> 界面差异说明：模型列表、插件、专家和集成项会随账号权限与安装情况变化；本手册描述的是默认安装加登录后的形态。

## 这本手册写给谁

如果你已经用过 ChatGPT 这类对话产品，但第一次接触"能自己动手改文件、跑命令、连服务器"的 Agent 工作台，这本手册从零讲起。它不假设你写代码——第 1、2、4、5、6 章对任何职业都成立；第 9、10 章偏开发；第 13 到 17 章偏进阶和运维。

每一章的结构是固定的：先说这一章解决什么问题，再一步步给操作，最后给一份"检查点"，让你确认自己确实做到了。

## 阅读约定

- `⌘` `⌥` `⇧` `⌃` 分别是 Command、Option、Shift、Control。
- **工作区**：一次任务允许读写的目录范围，可以是一个项目，也可以是多个目录。
- **运行位置**：命令到底在哪台机器上执行——本机、SSH 主机，还是远端 daemon。
- **交付物**：这次任务产出的可验证结果，代码改动、测试输出、图片、报告都算。
- 界面文案用引号标出，例如点击"新聊天"；菜单路径用箭头，例如「设置 → 运行时」。
- 凡是涉及删除数据、对外发布、发消息、付款、动生产库和密钥的操作，手册一律建议保留人工确认，不给"省事"的替代写法。
