# Open Core Model

WillDeep uses an **Apache 2.0 + Open Core** model.

This document explains the boundary between the open source project and possible commercial offerings. It is intended to make the project's business model explicit without weakening the open source rights granted by [LICENSE](LICENSE).

## Open Source Core

Unless a file says otherwise, the code and documentation in this repository are licensed under the [Apache License 2.0](LICENSE).

That means you may use, copy, modify, distribute, and create derivative works from the open source core, including for commercial purposes, as long as you comply with the Apache 2.0 terms.

The open source core is expected to include:

- The native macOS editor.
- Local file browsing and editing.
- Bring-your-own-key Agent mode.
- Local Agent tool execution with approval controls.
- Keychain-backed local credential storage.
- MCP and skill integration implemented in this repository.
- The `willdeep-agent` remote daemon included in this repository.
- Local tests, documentation, and build scripts included in this repository.

## Commercial Offerings

WillDeep may offer paid products or services around the open source core. These offerings do not remove or reduce the Apache 2.0 rights for code already published in this repository.

Commercial offerings may include:

- Official signed and notarized macOS builds.
- Automatic updates and stable release channels.
- Cloud sync for settings, sessions, memory, skills, and MCP configuration.
- Hosted remote runtimes and managed execution environments.
- Official model routing, usage analytics, billing, and fallback infrastructure.
- Premium or curated skill marketplace content.
- Team workspaces, shared policies, audit logs, and admin controls.
- Enterprise support, private deployment assistance, compliance reviews, and custom integrations.

Commercial features may be delivered through separate services, private repositories, paid binaries, hosted infrastructure, or enterprise agreements. Their availability does not change the license of the open source core.

## Contribution Licensing

Unless explicitly stated otherwise, contributions submitted to this repository are accepted under the Apache License 2.0, matching the license of the open source core.

If a contribution is intended to use different terms, that must be discussed and agreed before it is submitted.

## Trademark And Brand

The Apache License 2.0 grants copyright and patent rights, but it does not grant trademark rights.

The WillDeep name, logo, product identity, domain, and release branding may not be used in a way that implies official endorsement, official distribution, or partnership without permission. Forks and redistributions should use their own branding unless they are clearly presented as unofficial builds of WillDeep.

## Practical Summary

- You can use the open source core commercially under Apache 2.0.
- You can fork and modify the open source core.
- You can redistribute your modified version if you comply with Apache 2.0.
- You cannot claim your fork is the official WillDeep product unless authorized.
- Paid WillDeep services may exist alongside the open source core.
- Code already released under Apache 2.0 stays under Apache 2.0.

# Open Core 模式

WillDeep 采用 **Apache 2.0 + Open Core** 模式。

本文用于说明开源项目与未来商业产品/服务之间的边界。它的目的不是削弱 [LICENSE](LICENSE) 授予的开源权利，而是把商业模式说清楚。

## 开源核心

除非具体文件另有说明，本仓库中的代码和文档均采用 [Apache License 2.0](LICENSE)。

这意味着：只要遵守 Apache 2.0 条款，你可以使用、复制、修改、分发本仓库的开源核心，也可以基于它创建衍生作品，包括商业用途。

开源核心预期包括：

- 原生 macOS 编辑器。
- 本地文件浏览与编辑。
- 用户自带 API Key 的 Agent 模式。
- 带审批控制的本地 Agent 工具执行。
- 基于 Keychain 的本地凭据存储。
- 本仓库实现的 MCP 与 skill 集成。
- 本仓库包含的 `willdeep-agent` 远端 daemon。
- 本仓库包含的本地测试、文档与构建脚本。

## 商业产品与服务

WillDeep 可能围绕开源核心提供付费产品或服务。这些商业能力不会移除或削弱本仓库中已按 Apache 2.0 发布代码的开源权利。

商业产品或服务可能包括：

- 官方签名与公证的 macOS 构建。
- 自动更新与稳定发布渠道。
- 设置、会话、记忆、skills、MCP 配置的云同步。
- 托管远端 runtime 与受管执行环境。
- 官方模型路由、用量分析、统一计费与故障切换基础设施。
- 高级或精选 skill marketplace 内容。
- 团队工作区、共享策略、审计日志与管理控制台。
- 企业支持、私有部署协助、合规审查与定制集成。

商业能力可以通过独立服务、私有仓库、付费二进制、托管基础设施或企业协议交付。它们的存在不改变开源核心的许可证。

## 贡献许可

除非另有明确声明，提交到本仓库的贡献默认按 Apache License 2.0 接受，与开源核心保持一致。

如果某项贡献希望采用不同条款，需要在提交前讨论并达成一致。

## 商标与品牌

Apache License 2.0 授予的是版权与专利相关权利，不授予商标权。

WillDeep 名称、Logo、产品身份、域名和发布品牌不得在未经许可的情况下用于暗示官方背书、官方分发或合作关系。Fork 和再分发版本应使用自己的品牌，除非明确标注为非官方 WillDeep 构建。

## 简明总结

- 你可以按 Apache 2.0 将开源核心用于商业用途。
- 你可以 fork 并修改开源核心。
- 你可以在遵守 Apache 2.0 的前提下分发修改版。
- 未经授权，不能声称自己的 fork 是 WillDeep 官方产品。
- 付费 WillDeep 服务可以与开源核心并存。
- 已按 Apache 2.0 发布的代码，会继续保持 Apache 2.0。
