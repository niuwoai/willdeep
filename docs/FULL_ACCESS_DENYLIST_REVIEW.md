日期：2026-10-27。修复候选：Mac 1.425.0-rc2 / Rust CLI 0.122.0-rc3；未发布、未替换运行中的应用或 Runtime。

## 事故与结论

定时任务及实际会话均为 silent（完全访问）。2026-10-26 22:16:36（北京时间）审计的 full-access-denylist 把 SSH 日志统计命令判成 reverse-shell。搜索文本 sync bridge wait 中的 nc 空格与另一命令 grep -c 的参数被拼成依据。不是定时任务没有保存或传递模式，也不是运行后切换模式。

只给 nc 加词边界不能解决同类问题：引用文本、选项值、不同命令和嵌套脚本仍会混淆。此次移除整行关键词拼接，分别解析命令、参数、重定向与支持范围内的数据流。

## 产品策略与分析边界

结果区分 matched、notMatched、unsupportedSyntax。完全访问对命中的高影响操作保留确认，不调用 AI 裁判。未支持语法记录独立 unsupported 审计，继续遵守完全访问授权，既不伪装成恶意命中，也不宣称安全。已移除旧子串兜底。

这是有界静态检查，不执行输入、不连接 SSH、不读取变量值或凭据。它不是完整 shell 解释器或沙箱：动态 eval/动态可执行文件、heredoc、复杂分组和超出递归深度会报告限制；任意解释器程序、函数、别名与复杂文件描述符流不保证完整推断。凭据规则判断命名约定的来源及已支持的传输形态，不能识别任意文件内容或证明用户意图。

Mac 与 Rust 的产品政策不强行合并：Rust 原有破坏性命令确认边界更严格。本次同步修复关键词误判，保留各自真实操作的保护范围。
