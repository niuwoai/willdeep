# 第 8 章：快捷键、排错与最佳实践

[上一章：设置与远端运行](07-settings-runtimes.md) · [返回索引](README.md)

## 1. Agent 常用快捷键

| 快捷键 | 动作 |
|---|---|
| `Command+Shift+A` | 打开 Agent 窗口 |
| `Option+Command+A` | 显示或隐藏项目 Agent 面板 |
| `Command+N` | 新建会话 |
| `Command+F` | 在当前会话中搜索 |
| `Command+,` | 打开设置 |

## 2. 编辑器常用快捷键

| 快捷键 | 动作 |
|---|---|
| `Command+O` | 打开文件 |
| `Shift+Command+O` | 打开文件夹 |
| `Command+P` | Quick Open |
| `Command+Shift+P` | 命令面板 |
| `Command+F` / `Command+G` | 查找 / 下一个匹配 |
| `Command+L` | 跳到行 |
| `Command+Shift+O` | 跳到当前文件符号 |
| `Command+Option+R` | 切换 Markdown / HTML 预览 |
| `Command+Option+\` | 打开分屏文件 |
| `Command+Option+I` | 切换检查器 |
| `Command+1…9` | 切换对应标签 |
| `Command+[` / `Command+]` | 前后切换标签 |
| `Command+Shift+T` | 恢复刚关闭的标签 |

## 3. 模型不可用或列表为空

按顺序检查：

1. some.im 是否已登录，或自有 provider 是否已保存。
2. Base URL 和模型名是否正确。
3. API Key 是否有效且有对应模型权限。
4. 在模型选择器中点击“重新加载模型目录”。
5. 网络、代理和 provider 服务是否可达。

不要在报错截图中露出完整 Key、Authorization header 或包含凭据的 URL。

## 4. Agent 看不到文件

- 确认当前会话绑定的是正确工作区。
- 检查文件是否位于工作区之外。
- 确认 macOS 文件访问权限。
- 大型依赖和构建目录可能被默认忽略。
- 远端会话检查默认远端工作区路径。

## 5. 工具一直等待审批

- 查看对话中的审批卡片。
- 确认当前审批模式。
- 多张卡片同时存在时逐一核对工具名和参数。
- 高风险操作可能需要输入 `confirm`，不能只点击普通批准。
- 移动网关通知只能提醒，最终批准仍应核对桌面端上下文。

## 6. 终端命令跑错位置

立即停止继续输入，并检查：

```bash
hostname
pwd
git status --short --branch
```

然后确认终端标签、会话绑定、工作区和 runtime。涉及生产服务时先保留现场，重启不是第一反应。

## 7. 远端 runtime 连接失败

- 在系统终端手动验证 `ssh user@host`。
- 检查端口、防火墙、私钥路径和权限。
- 确认远端工作区存在且用户有权限。
- daemon 模式检查 Base URL、Token 和服务状态。
- 使用设置中的探测功能读取平台和工具链信息。

## 8. 媒体任务卡住

- 切到“卡住”或“需处理”筛选。
- 查看 provider 的任务状态和额度。
- 检查输入图片、蒙版和提示词格式。
- 不要重复点击生成导致多个高成本任务并行。
- 需要重试时先记录原任务 ID 和错误信息。

## 9. App 卡顿或无响应

- 先观察 CPU、内存和当前后台任务。
- 检查是否打开超大 Diff、长会话、巨型文件或大量媒体缩略图。
- 记录当前工作区、会话和最后一个操作。
- 保存未提交内容后再考虑重启。
- 可复现时提供版本号、macOS 版本、步骤和最小样本。

## 10. 日常使用最佳实践

- 一个会话一个目标，复杂任务先计划。
- 每个请求写清范围、验收和禁止项。
- 修改前看工作树，完成后看 Diff。
- 先运行最相关的测试，再扩大验证范围。
- 远端和生产操作始终核对主机与目录。
- 自动化默认只读，外部副作用人工确认。
- 密钥进 Keychain/`.env`，不进聊天、日志和 Git。
- 最终交付保留文件路径、测试结果和已知风险。
