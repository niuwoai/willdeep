# WillDeep Business Model Notes

> Last updated: 2026-06-13 | Current version: v1.67.0-rc2

本文记录 WillDeep 采用 **Apache 2.0 + Open Core** 后的商业化判断。它不是定价承诺，也不是法律意见；它用于帮助团队判断哪些能力应该开源，哪些能力适合商业化，以及怎样避免把产品带进低价竞争。

## 核心结论

WillDeep 有赚钱机会，但不应该靠“开源编辑器本体”赚钱。

真正可售卖的是：

- 可信之后的省心体验。
- 团队级权限治理。
- 可审计的 Agent 执行链路。
- 远端 runtime 与托管执行环境。
- 模型管理、用量分析、统一账单。
- 可复用的 workflow、skill 与 MCP 资产。

一句话：**不要卖编辑器，卖“安全可控地让 Agent 替个人和团队干活”的能力。**

## 开源的商业意义

WillDeep 的核心能力天然触碰用户高信任门槛：

- 本地文件访问：编辑器可以读写用户代码。
- Agent 工具执行：可以运行命令、修改文件、连接远端 runtime。
- 凭据管理：API Key、MCP header/env、daemon token 等敏感信息会进入本地配置或 Keychain。
- 自动化与后台任务：Agent 可以在用户不盯着窗口时继续执行任务。

因此，开源的第一价值不是“让别人帮忙写代码”，而是**降低信任摩擦**。开发者工具用户会问：它有没有偷传代码？命令审批边界在哪里？凭据是否真的只在本地？闭源只能解释，开源可以验证。

开源还可以带来三个商业收益：

- **信任背书**：本地优先、BYOK、Keychain、命令审批、远端 daemon 的安全承诺更容易被接受。
- **生态入口**：skill、MCP、远端 runtime 的扩展能力更容易吸引高级用户参与。
- **心智差异化**：在大量闭源 AI IDE 里，WillDeep 可以站到“可信、可审计、原生、本地优先”的位置。

## 竞争风险

开源会带来竞争风险，但风险的主要来源不是普通 fork。

源码可以复制，难复制的是：

- macOS 原生体验的长期打磨。
- Agent 权限模型与审批交互。
- 产品取舍。
- 发布节奏。
- 品牌信任。
- 官方签名构建、自动更新、文档、社区与支持。

真正的竞争者通常会来自三类：

- 大团队借鉴产品方向后重新实现。
- 小团队 fork 后换皮低价分发。
- 社区分支在某些功能上跑得更激进。

应对策略不是闭源，而是把护城河放在更难复制的位置：

- 官方品牌和签名分发。
- 稳定可靠的 release pipeline。
- 托管 runtime、云同步、团队治理等服务端能力。
- 高质量 skill marketplace。
- 企业部署、合规、安全支持。

不开源也挡不住真正的竞争者；开源反而能让 WillDeep 先占住“可信原生 Agent 编辑器”的心智。

## 不该走的赚钱方式

以下方式不适合作为主收入来源：

- **一次性买断编辑器**：收入不稳定，且不匹配持续模型、云服务和支持成本。
- **主题和小插件售卖**：价值太轻，容易把产品带偏。
- **模型差价作为唯一收入**：BYOK 用户会绕开，且容易伤害信任。
- **过度阉割开源版**：Open Core 最忌讳开源版像试吃牙签，会伤害社区信任。
- **宣传成免费 Cursor 平替**：会把产品拖进价格战，也会模糊 WillDeep 的本地可信定位。

## 推荐商业层

### Community

定位：开源核心，用于建立信任和开发者心智。

建议包含：

- 原生 macOS 编辑器。
- BYOK Agent。
- 本地工具执行与审批。
- 基础 MCP / skill 集成。
- 本地 Keychain 凭据存储。
- 本地会话与配置。
- `willdeep-agent` 基础 daemon。

Community 版应该足够好用，不能只是广告牌。它承担的是信任、传播和生态入口。

### Pro

定位：面向高频个人用户，卖省心和增强体验。

可包含：

- 官方签名与公证构建。
- 自动更新。
- 云同步设置、会话、记忆、skills、MCP 配置。
- 高级 Agent memory。
- 官方精选 skills。
- 模型用量分析与成本提示。
- 小额度托管 runtime。
- 更稳定的 release channel。

参考价格区间：

- 月付：8-15 美元。
- 年付：80-120 美元。

Pro 可以带来早期现金流，但不应成为唯一增长引擎。

### Team

定位：面向团队，卖治理、协作和审计。

可包含：

- 团队共享 provider / MCP / skill 配置。
- 团队命令审批策略。
- 禁止命令与允许命令策略。
- Agent 操作审计日志。
- 成员与工作区权限。
- 统一模型网关与账单。
- 团队共享 memory 或知识库。
- 私有 skill marketplace。

参考价格区间：

- 20-40 美元 / 人 / 月。

Team 是最自然的商业主线。个人用户买工具，团队买可控性。

### Enterprise

定位：面向对安全、合规和私有部署有要求的组织。

可包含：

- 私有部署。
- 内网模型接入。
- 私有 MCP / runtime 集成。
- SSO / SCIM / RBAC。
- 审计日志导出。
- 合规和安全评估支持。
- SLA。
- 定制开发与培训。

Enterprise 不应该只是一组功能开关，而应该是交付能力和信任背书。

### Hosted Runtime

定位：中长期增长点，卖执行环境和基础设施。

可包含：

- 托管远端 runner。
- 隔离沙箱。
- 云端编译、测试、脚本执行。
- 长任务后台运行。
- 日志、任务历史和 artifact。
- repo 级权限控制。
- 可选 GPU / 大内存 / 特定工具链环境。

Hosted Runtime 的价值很高，但成本也高。适合在 Community 和 Pro 验证出强需求后再加速。

### Model Service

定位：BYOK 之外的可选增强。

原则：

- BYOK 永远保留，不能强迫用户走官方模型账户。
- 官方模型服务卖的是统一账单、fallback、限额、统计和团队治理。
- 不把模型差价包装成唯一商业模式。

可包含：

- 多模型统一账单。
- 团队配额管理。
- 模型 fallback。
- 用量报表。
- 成本中心。
- provider outage 时的自动切换。

## 产品定位

推荐对外定位：

> A trusted, native, local-first, auditable Agent development environment.

中文可以表达为：

> 可信、原生、本地优先、可审计的 Agent 开发环境。

不推荐的定位：

- 免费 Cursor 平替。
- 又一个轻量编辑器。
- 又一个聊天框 IDE。
- 便宜版 AI 编程工具。

WillDeep 应该和主流闭源 AI IDE 拉开位置。Cursor 的主战场是云模型驱动的 AI IDE；WillDeep 可以站在本地可信、原生体验、可控 Agent、团队治理这边。

## 阶段路线

### 阶段 1：开源信任

目标：

- 完成 Apache 2.0 + Open Core 文档。
- 补齐 SECURITY.md。
- 统一 WillDeep 品牌。
- 清理或分层 BundledSkills。
- 保持 Community 版可独立使用。

核心指标：

- GitHub stars。
- Issue 质量。
- 外部贡献者数量。
- 用户是否愿意把真实项目放进 WillDeep。

### 阶段 2：个人 Pro

目标：

- 官方签名版。
- 自动更新。
- 配置/会话/记忆云同步。
- 高级 skill 与模型用量统计。

核心指标：

- 免费到付费转化率。
- 月留存。
- 高频用户每周使用时长。
- 付费取消原因。

### 阶段 3：团队治理

目标：

- 团队共享配置。
- 审批策略。
- 审计日志。
- 统一模型账单。
- 私有 skill marketplace。

核心指标：

- 每团队 seat 数。
- 团队内活跃成员比例。
- 审计/策略功能使用率。
- 企业试用转化率。

### 阶段 4：托管执行与企业

目标：

- Hosted Runtime。
- 私有部署。
- SSO / RBAC。
- 企业安全支持。
- 定制集成。

核心指标：

- 年合同额。
- runner 使用时长。
- 企业续费率。
- 支持成本占比。

## 关键原则

- 开源核心必须真实可用，不能做成残缺演示版。
- 商业化重点放在省心、协作、治理、托管和支持。
- BYOK 是信任底线，不应取消。
- 官方模型服务是可选增强，不是强制通道。
- 团队版卖的是控制力，不只是更多按钮。
- Hosted Runtime 要晚一点做，先验证需求再烧钱。
- 不参与“谁更像 Cursor 但更便宜”的叙事。

## 最终判断

WillDeep 有赚钱机会，但它的商业价值不在“编辑器”这个名词里，而在“可信 Agent 开发环境”这件事里。

如果坚持开源核心、商业化体验层和团队治理层，它可以形成健康的 Open Core 路线。如果摇摆成普通轻量编辑器加聊天框，就容易被大产品吞没，也很难支撑付费。

最稳的路线是：

1. 开源核心拿信任。
2. Pro 版赚个人高频用户。
3. Team / Enterprise 赚治理、审计、统一配置。
4. Hosted Runtime 作为中长期增长点。
5. BYOK 永远保留，官方模型服务只做可选增强。
