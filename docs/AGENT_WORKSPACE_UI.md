# 智能体工作区

版本：1.422.0-rc2（构建 924）。

主会话侧栏的「智能体库」和「RSI 实验」打开独立工作区。设置中的原版本库入口跳到同一个工作区，不再在设置弹窗内套实验弹窗。

## 智能体库

左侧按名称或标识搜索，并筛选本机、私有、官方来源；右侧编辑定义。创建、导入、官方目录刷新与安装、私有同步、派生、导出、固定版本和回滚、冲突解决、本机模型绑定均沿用原版本库方法。官方定义只读，须派生用户副本后编辑或实验。完整 JSON、技能正文和哈希收在高级详情中；版本历史菜单保留短哈希以区分同版本分叉。

「some.im · 已连接」只说明存在当前已验证账号，不声称已同步。同步完成必须以本次同步结果为准。

## RSI 实验

1. 选择用户基线；官方或签名定义先派生副本。
2. 并排核对基线和候选，修改候选版本与指令。实验备注仅保存在本机，不参与同步或评分。
3. 保存候选；不会替换当前安装、取消固定或自动晋升。备注单独保存在按账号隔离的 `presentation.json`，不扩展共享候选、实验或证据契约。
4. 运行「免费验证」，沿用原生 Worker 的隔离 mock 配对执行链。它验证执行证据与契约，不代表真实模型质量提升。

近期实验只读取实际保存的 spec 和 evidence，时间仅取匹配证据的 `finished_at`。未运行不伪造状态或更新时间。上传默认未授权；选中授权后才向当前 some.im 账号上传原定义允许的摘要，撤销按钮沿用原 grant 撤销 API。

切页面、换基线、加载另一候选或选择另一库条目前，未保存修改需明确放弃。账号变化立即清除全局基线、编辑内容、结果、备注和上传授权；运行、上传、撤销使用账号与会话代际校验，防止 A → B → A 后接受旧响应。

工作区自己的窗口关闭代理保留并转发 SwiftUI 原窗口委托。存在未保存内容时先要求「继续编辑」或「放弃修改并关闭」，取消不改编辑文字；干净窗口正常关闭，不改变全局 AppDelegate 或其它窗口的退出行为。确认意图使用独立标识，允许 SwiftUI 先收起对话框再执行按钮；等 sheet 收起后有界异步关闭，仅实际 `windowWillClose` 事件清理脏修改标记。关闭未发生则恢复原保护，不留下无保护的编辑窗口。关闭意图可用 `ruby scripts/test_agent_workspace_close_guard.rb` 直接编译生产状态机验证，另输出 JSON 和中文 Markdown；此项不能替代真实 AppKit 对话框验收。

## 隔离预览

`scripts/build_agent_workspace_preview.rb` 只接受独立的 `/private/tmp/xedit-agent-workspace-preview-cache-*` 缓存，不能覆盖原生测试宿主。使用 APFS `clonefile` 创建缓存，无普通复制回退、无硬链接；构建保留 6 GiB 空闲预留。

```sh
ruby scripts/build_agent_workspace_preview.rb --cache-root /private/tmp/xedit-agent-workspace-preview-cache-20261016
```

该 Debug 变体显式选择独立的 `AgentWorkspacePreviewApp` 入口，bundle identifier 为 `com.willdeep.workspace-preview`，没有产品 AppDelegate、AppState、真实会话恢复、定时任务、插件任务和模型探测。为限制临时磁盘用量仅关闭 DWARF，保持 Debug、原优化级别和断言；此配置不是正式发布配置。预览库、RSI 存储和 UserDefaults 都独立；远端目录、同步与上传禁用。本地创建候选和免费离线验证仍使用产品同一实现。

迁移缓存时，SwiftPM manifest 与 ComputerUseHelper 的 PCM 缓存包含绝对目录，必须使用预览自己的新模块缓存；其余可迁移对象和 Go 缓存可按同字节、无硬链接的 CoW 方式复用。目录迁移拒绝属于构建环境证据，不计为产品测试失败。

启动时设置 `WILLDEEP_AGENT_WORKSPACE_PREVIEW_ROOT` 为新的 `/private/tmp/` 目录，再执行预览 App 的 `Contents/MacOS/WillDeep`；构建报告给出精确启动数组。不得覆盖 `/Applications/WillDeep.app`。

图稿的蓝色 W 不属于现有品牌，因此使用实际蓝色双环 AppIcon、WillDeep 字样与 SF Symbols。此项是有意保留的品牌差异。原生按钮、菜单和编辑器沿用系统控件；界面截图与交互须由实际预览核验，不能由编译通过代替。

## 验证边界

新增 `AgentWorkspacePresentationTests` 的 12 项测试覆盖备注与账号隔离、定义哈希不变、官方派生、搜索与来源过滤、未保存切换、历史基线回选、账号代际、真实证据时间及独立预览库。其中操作门禁同时覆盖排队开始前、悬停成功和失败后的 A → B → A，以及当前账号正常完成，防止旧操作覆盖新账号提示或忙碌状态。

与版本库、冲突及 RSI 现有相关组一起，原生实测 47/47 通过、0 失败、0 跳过。RSI 原生组执行真实 Worker 配对 mock（完整 6 条与中途中止 5 条），没有真实模型调用；未提供 HTTP 联调配置，本轮不声称 some.im 跨端 HTTP 验收。独立预览已编译并启动，视觉与关闭重开生命周期由实际操作另行核验。实际结果另存验证报告。此次不合并、不推送、不安装，不运行真实模型。

第一次真实预览发现关闭窗口会丢未保存文字，已据此增加上述窗口专用确认；后续实际操作发现同步关闭会只消除确认框，故补确认令牌和异步收起时序。关闭意图的独立 18 条免费断言及预览增量编译通过，不把原 47 项冒认为新增关闭保护的全工程重跑。紧凑首屏将说明移入折叠行，版本放卡头、基线用浅灰只读面、候选编辑框固定约 205 点，编辑修改会推进第二步骤。最终对话框取消/明确放弃和同屏布局仍以实际截图与交互记录为准。

最终原生预览已实际验证：取消关闭保留原文字、明确放弃后独立窗口清单中预览消失；保存候选后基线安装不变，运行生成真实 Worker/mock 的 6/6 完整证据、全部零费用，近期实验同步显示这次本机结果。第二轮同屏与库界面截图通过。详见 `docs/verification/1.422.0-rc2/agent-workspace.md`；这些是隔离预览的本机免费验收，不是已安装版本变更或真实模型质量评测。
