# Product Overview

> 当前版本：0.1.0 | 2026-09-09

《车间大暴走》是 WillDeep 的单人离线漫画游戏插件。笑点针对虚构车间的荒诞管理，采用原创人物、场景和卡通道具，不出现真实厂名或商标。

首版可玩暴走老哥：避开两位寻路追赶者、收集三个通行章、限时逃出。大厅采用深蓝和警示黄漫画风，实际对局使用俯视角，完整地图始终可见。角色暂用单帧素材，世界逻辑采用固定步长。

React 负责 UI，Canvas 2D 负责地图和角色，TypeScript 纯逻辑模块提供碰撞、寻路、投掷与胜负规则。所有资源打包到 `ui/dist/client`，不提供服务端 API，也不申请网络、会话或工作区权限。

后续：班长可玩模式、多方向跑步帧、更多车间变化。实际宿主安装与跨插件切换验收不包含在浏览器预览验证中。
