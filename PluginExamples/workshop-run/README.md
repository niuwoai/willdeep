# 车间大暴走 / Workshop Run

班可以加，厕所不能等。一款完全虚构、单人离线、三分钟一局的 WillDeep 漫画追逐游戏。

## 玩什么

扮演白背心、粉色短裤的暴走老哥，在电池车间收集三个不同通行章，从右上角出货口逃出。绕货架甩开两位 AI 班长，用卡通便便减速，或者暂时躲进纸箱。角色、场景和企业背景全部虚构，素材使用内置 imagegen 原创生成。

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键，也可长按屏幕方向按钮 |
| 投掷 | J，鼠标瞄准或朝最近移动方向 |
| 冲刺 | K / Shift |
| 收集、躲藏、补给、休息、出门 | E |
| 暂停 / 继续 | Esc |

厕所安全区每局可休息两次，每次安全五秒；离开安全区前后保护均按剩余时间计算。补给点每十五秒可以补满三发。被持续接触 1.2 秒或超过 180 秒则失败。

## 内置发行与安装

从 WillDeep 1.357.0-rc1 起，本游戏接入 App 内置插件打包流程。安装该版 App 后，插件中心会自动发现并启用「车间大暴走」，不需要手动导入 ZIP 或单独批准。游戏不强制固定在侧栏，用户可自行固定或停用。

Xcode 的 `Bundle built-in plugins` 阶段仅将双清单、本地化与 `ui/dist/client` 复制到 `WillDeep.app/Contents/Resources/BundledPlugins/workshop-run`，不包含开发依赖、源码、测试、Sites Worker 或报告。

兼容的旧版宿主也可手动安装：在 WillDeep 插件中心选择「添加插件」，导入 `willdeep-workshop-run-v0.1.0.zip` 或本目录，核对目的地为“车间大暴走”、权限为空，然后批准安装并启用。无需安装 Node、启动服务或填写模型密钥；安装包已经包含网页构建产物。

手动导入的批准由用户在插件中心完成；内置版本沿用宿主自动批准规则。本项目脚本不会写入或修改插件注册表。

## 开发

在 `ui` 目录执行 `yarn install --frozen-lockfile`、`yarn dev`。验证使用 `yarn test` 和 `yarn build`。开发构建使用 React / TypeScript / Canvas 2D / Vite，图片和脚本均在包内。

构建后运行 `node scripts/preview-plugin.mjs` 可在端口 4189 预览静态产物，启用与宿主相近的禁止联网 CSP。该预览不等于实际 WKWebView 安装验收。

插件根目录运行 `ruby scripts/package.rb [输出目录]` 生成 ZIP、SHA-256 和 JSON / Markdown 检查报告。打包仅包含双清单、本地化、编译页面及产品文档，不包含依赖目录或源代码工作区。

## 当前边界

- 0.1.0 只有老哥对战 AI，班长可玩模式标为后续开放。
- 设置与纪录使用可降级的浏览器存储；WillDeep 非持久化 WebView 可能只保留本次会话数据。
- 地图和机台有碰撞，角色使用原创单帧图片配合移动反馈；尚未制作多方向逐帧跑步动画。
- 没有联机、云排行榜、聊天读取、工作区访问或模型调用。
- 已完成浏览器与逻辑验收；内置发行另有 App 包加载与默认启用测试。实际用户安装、跨插件切换和 Rust Web 宿主兼容性仍需分别验收。
