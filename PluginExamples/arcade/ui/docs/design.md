# 设计决策与 UI 规范（design.md）

> 冻结于 rc1。改动 UI token 需升级契约并同步 `src/styles.css`。

## 1. 设计方向

街机游戏大厅：深色背景 + 高对比强调色，单屏信息密度低、聚焦“选择即玩”。

选定方向：**深色 Arcade**（`#0f1420` 底色 + 蓝紫强调 `#4f8cff`），
卡片式大厅，触屏优先的大可点目标。

备选方向（未选）：明亮糖果色（高饱和、儿童向）、赛博霓虹（高动态、
纯装饰性文字多，不利于长会话）、极简黑白（缺少游戏氛围）。

## 2. 设计 Token（冻结）

定义于 `src/styles.css` 的 `:root`：

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#0f1420` | 页面底色 |
| `--bg-panel` | `#171d2e` | 卡片/面板 |
| `--fg` | `#e8ecf4` | 主文字 |
| `--fg-muted` | `#8b93a7` | 次要文字 |
| `--accent` | `#4f8cff` | 强调/交互态 |
| `--accent-strong` | `#7aa8ff` | 悬停/数值 |
| `--border` | `#262e44` | 分隔线 |
| `--radius` | `10px` | 圆角 |
| `--space` | `16px` | 基础间距 |

字体：系统字体栈（含 PingFang SC / Microsoft YaHei），无需加载网络字体。

## 3. 布局与响应式

- 大厅卡片：`grid-template-columns: repeat(auto-fill, minmax(240px, 1fr))`，
  窄屏自动单列。
- 游戏外壳：标题 + 元信息 + 玩法区（居中）+ 底部操作说明。
- `<560px` 时外壳头部改为纵向堆叠。
- 可点目标最小高度 44px（`min-height: 40px` + padding 满足触屏规范）。

## 4. 组件状态设计

- 大厅：标题、副标题、语言切换按钮、卡片（标题/描述/最佳成绩）。
- 游戏外壳：返回链接、标题、最佳成绩徽章、种子徽章（有 seed 时）、操作说明。
- 空状态：无成绩显示“暂无记录”；未知路由渲染 404 页。
- 加载/错误状态：占位阶段无需异步加载；正式游戏模块若有异步逻辑须自带
  加载与失败态，并遵守 data-testid 命名契约。

## 5. 多端规范

- 语义一致：同一游戏在大厅卡片、外壳标题、操作说明中含义相同。
- 布局按平台习惯：桌面宽屏卡片多列；移动端单列 + 触控大按钮；
  键盘游戏（snake/tetris）同时提供屏幕按钮或手势（由各游戏节点实现）。
