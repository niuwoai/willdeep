# i18n 决策（i18n.md）

> 冻结于 rc1。新增语言时按第 3 节执行。

## 1. 范围与默认

- 首发语言：简体中文（zh-Hans，默认）、English（en）。
- 默认语言：zh-Hans（`index.html` 的 `lang` 与 `I18nProvider` 一致）。
- fallback：当前语言 → zh-Hans → 原样返回 key（便于发现缺失 key）。
- 数字/日期格式：本项目成绩仅整数，无本地化格式需求；时间戳仅内部使用。
- 非 RTL 语言。

## 2. 方案选择

自研轻量字典（约 40 个 key）而非引入 react-i18next / FormatJS：

- key 规模小，自研实现 < 100 行，无配置负担；
- 无额外运行时依赖，包体积最小化；
- 需要 `{param}` 插值（种子徽章等）已支持。

## 3. 约定（硬性）

- 视图代码**零硬编码用户可见文案**，一律 `t(key)`。
- `src/core/i18n/zh-Hans.ts` 的 key 集合是平台契约；
  `en.ts` 必须与其完全同构（有单元测试强制，`i18n.test.tsx`）。
- 语言切换入口：大厅右上角 `data-testid="lang-switch"`；
  选择持久化到 `arcade.locale`。
- 新增语言：新增 `<lang>.ts` 字典 → 加入 `SUPPORTED_LOCALES` 与
  `dictionaries` → 补测试。

## 4. 关键实现位置

- `src/core/i18n.tsx`：Provider、`useI18n`、`t(key, params)`、持久化。
- `src/core/i18n/zh-Hans.ts`、`src/core/i18n/en.ts`：字典。
- `src/core/testid.ts`：语言切换按钮的 testid。
