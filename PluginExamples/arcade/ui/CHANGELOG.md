# Changelog

本项目遵循语义化版本。构建号未单独管理（纯静态前端，无发布产物号）。

## [0.6.0] - 2026-08-27

### 新增

- **印加弹珠：断口撞出的三连也算连锁**。消掉一段之后，两侧珠子被追赶合拢、如果撞在一起又凑够三颗同色，
  除了原有的连锁得分，现在还会**把链条整体往回顶一段**（约 6 个身位，走同一套加速回退管线），
  并在接合点放一圈金色星芒庆祝特效 + 提示音，同时触发外壳撒花。

### 变更

- **乒乓球整体重制为 canvas 版**：画了真正的球桌（深绿毛毡按左上 45° 打光、白色边线与中线、
  带竖栏和顶边高光的球网）、带渐变与投影的圆角球拍、径向高光的橙白色球（球下有椭圆投影）。
  丢球之后**停 1 秒再发球**（球在中线呼吸提示），发球方向朝上一次丢球的一方。
  逐帧状态放 ref 由 requestAnimationFrame 驱动，React 只在比分/关卡变化时重渲染；
  球拍与球的位置同时挂在 canvas 的 `data-*` 上，e2e 不用去猜画布像素。

## [0.5.0] - 2026-08-27

### 变更（玩法）

- **七款游戏全部改为关卡自动进阶，不再让玩家手选难度**：通关即自动进入下一关（停顿 1.9 秒放撒花），
  分数跨关累计，外壳右上角常驻「关卡 N」「分数 X」两枚徽章（`GameProps.onStage` 上报，见 `core/stage.ts`）。
  - 记忆翻牌：2 对起步，每关 +1 对，12 对封顶；列数随牌数自动接近方阵，配色扩到 12 种。
  - 连连看：4×4 → 6×4 → 6×6 → 6×8 → 8×8 封顶。
  - 印加弹珠：**真无限**——颜色 4→6、弹珠数每关 +8、开局链条每关 +2、速度每关 +0.45、炸弹与闪光珠同步变多。
  - 扫雷：雷数 10 起步每关 +2，30 颗封顶。
  - 贪吃蛇：目标食物 5 起步每关 +2，节拍每关快 12ms（90ms 封顶）。
  - 俄罗斯方块：等级即关卡，每级下落间隔快 55ms（140ms 封顶），无限。
  - 乒乓球：赢一局进下一关，球速与 CPU 跟球速度同步提升。
- 每款游戏都保留「重开」（重打本关）与「从头开始」（回到第 1 关、累计分归零）两个按钮。

## [0.4.0] - 2026-08-27

### 新增

- **印加弹珠开局弹簧入场**：开局那串弹珠先排在入口隧道里（`dist < 0`，不渲染），由一条阻尼振荡缓动
  （`springEase`）把整条链甩上轨道——中途过冲约 10% 再回弹落定，看起来是「弹进来」而不是匀速爬进来。
- **落洞动画与黄金骷髅**：队首碰到洞口不再瞬间判负，先进入新的 `falling` 阶段——整条链越掉越快地涌进洞口，
  弹珠逐颗被吞掉（渲染上按剩余距离缩小），吞完才落到 `lost`。洞口画成黄金浮雕骷髅头（金色渐变 + 迎光描边 +
  凹陷眼窝鼻腔与牙列），一眼就知道珠子滚到这儿意味着什么。
- **滚动与道具的加速手感**：缺口合拢的追赶速度随缺口大小变化（爆炸炸出的大缺口先猛冲、合拢时自然减速）；
  闪光珠的倒退不再瞬移，改为挂账后逐帧加速拉回（起步 24、加速度 190、上限 150 世界单位/秒）。

### 变更

- **弹珠改为带光照的球体**：光从左上方 45° 打过来，每颗珠子按颜色预生成一张带高光、暗环的球体精灵
  （逐帧只做缩放贴图，不重复算渐变），并在背光侧投一枚椭圆落地阴影；轨道改为「亮外沿 + 暗槽底」的凹槽画法。
  发射器上的当前/下一颗弹珠与飞行中的弹珠共用同一套材质。

## [0.3.0] - 2026-08-27

### 新增

- **印加弹珠道具珠**：链条上会随机长出炸弹珠（消掉时炸飞前后各约三个身位的一整片，炸到别的炸弹会连环引爆）
  和闪光珠（消掉时整条链往回倒退约十个身位，把已经跑到洞口的珠子拉回来）。两种珠子在场上分别画成
  深色芯 + 引信火花、脉动白环 + 回退箭头，消除瞬间各有一圈扩散特效；数量按关卡配置（简单 3/2、中等 4/3、挑战 6/4）。
- **通关撒花**：`src/ui/Confetti.tsx` 自绘 canvas 彩纸（不引第三方依赖），由 `GameShell` 常驻挂载。
  游戏通过新增的可选 prop `GameProps.onWin` 通知路由层触发；七款游戏全部接入——记忆翻牌/连连看/印加弹珠/
  扫雷/贪吃蛇/乒乓球在通关时撒，俄罗斯方块没有通关概念，改在刷新最佳成绩时撒。尊重 `prefers-reduced-motion`。
- **音效**：`src/core/audio.ts` 用 Web Audio 现场合成 20 个 8-bit 风格音效（翻牌、配对、消除、发射、爆炸、
  倒流、消行、踩雷、通关、失败等），**不打包任何音频素材，零版权风险**。外壳右上角有开关，状态存
  `arcade.sound`；没有 AudioContext 或被策略拦截时静默降级，绝不影响玩法。

## [0.2.0] - 2026-08-27

### 新增

- **连连看**（`src/games/onet/`）：4×4 / 6×4 / 8×6 三档难度，经典「连线拐弯不超过两次、可绕棋盘外围一圈」规则；
  纯逻辑 `findPath` 用扩展网格上的 0-1 BFS 求解，成功连接会在棋盘上画出折线；提示、洗牌、死局自动洗牌各自计入扣分。
- **印加弹珠**（`src/games/marble/`，Zuma 玩法）：弹珠沿螺旋轨道滚向洞口，中央发射器打进同色三连即消除，
  断口合拢可触发连锁倍率；引擎 `step(state, dt)` 为纯函数，canvas 只负责渲染，逐帧状态不进 React state。

### 变更

- **记忆翻牌每次重开都换一副牌**：牌组种子改为 `<基准种子>#<局数>`，重开即局数 +1；
  未通过 `?seed=` 指定种子时，每次进入游戏取一次性熵种子（`core/rng.ts` 新增 `entropySeed`）。
  「同一基准种子的第 N 局」依旧完全可复现，回归测试不受影响。
- **棋盘尺寸一律容器相对**：记忆翻牌 / 贪吃蛇 / 俄罗斯方块的棋盘从 `width: min(NNvw, …)` 改为
  `width: 100%` + 每格绝对上限。视口单位在插件面板里并不等于可视宽度，旧写法会让「挑战 · 6 对」
  这类布局被撑大并出现横向滚动条。`tests/e2e/layout.spec.ts` 增加棋盘 ≤ 容器、单张牌 ≤ 96px 的回归断言。

## [0.1.0] - 2026-08-03

### 新增（五游戏集成）

- 按字母序合并 `memory`、`minesweeper`、`pong`、`snake`、`tetris` 五项 GameManifest 注册；大厅由注册表生成五个导航入口。
- 移除大厅路由对 `DummyGame` 的依赖，五个独立游戏模块均接入键盘或触屏操作与 localStorage 最佳成绩。
- 更新 README、锁定范围和大厅回归用例以反映正式集成状态。

### 新增（冻结共享契约与可运行大厅骨架）

- 工程骨架：React 18 + TypeScript(strict) + Vite 5 + Vitest + Playwright + yarn 1，
  提供 `dev` / `build` / `test` / `test:e2e` / `typecheck` / `preview` 脚本。
- 冻结共享契约（`src/core/*`）：
  - `types.ts`：`GameId` / `GameManifestEntry` / `GameProps` / `BestScore` / `Locale`。
  - `games/manifest.ts`：GameManifest 五款游戏注册表（贪吃蛇/俄罗斯方块/Pong/扫雷/记忆翻牌）。
  - `hashRouter.tsx`：Hash 路由（`#/game/<id>?seed=`），`useRoute` / `navigate` / `Link`。
  - `safeLocalStorage.ts`：存储安全封装，成绩 key `arcade.best.<id>`。
  - `i18n.tsx` + `i18n/{zh-Hans,en}.ts`：默认 zh-Hans，`{param}` 插值，语言持久化。
  - `testid.ts`：data-testid 命名契约（`<scope>-<name>`）。
  - `rng.ts`：确定性种子（mulberry32 + FNV-1a）、`shuffle` / `pick` / `range`。
  - `input.ts`：`useKeyControls` 键盘输入清理契约。
  - `bestScore.ts`：`useBestScore` / `saveBestScore` 最佳成绩订阅。
- 可运行骨架：`ui/Lobby`（卡片大厅 + 语言切换）、`ui/GameShell`（外壳 +
  成绩/种子徽章）、`games/dummy/DummyGame`（占位演示游戏）、五个游戏模块占位。
- 回归：Vitest 单元测试（rng / safeLocalStorage / i18n / hashRouter / input /
  bestScore / App 路由与 dummy），Playwright e2e（大厅导航、语言切换）。
- 文档：README、ARCHITECTURE、docs/contracts.md、docs/design.md、docs/i18n.md、
  docs/locked-scope.md。
- 开发辅助：`scripts/dns-shim.cjs`、`scripts/retry-install.sh`（受限沙箱网络
  环境下安装依赖用）。
