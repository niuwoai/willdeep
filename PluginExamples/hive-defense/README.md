# 蜂巢防线

WillDeep 内置本地塔防插件，版本 1.338.0-rc1。原始玩法来自 `~/Sites/pylearn/hive.html`，修改前文件备份为 `hive.before-willdeep-20260907.html`；整合版本位于 `ui/index.html`，可直接在浏览器打开，或由 WillDeep 插件中心加载此目录。构建 App 时，Xcode 自动复制至 `BundledPlugins/hive-defense`。

5 种防御塔、6 种虫群、蜂巢基地、维修蜂和狗熊共 14 张独立透明 PNG，均位于 `ui/assets`。图片使用内置 imagegen 生成并保留原生 alpha。没有外链资源和运行权限。蜘蛛分裂后的幼体复用蜘蛛图并按原规则缩小。

林间访客：第 3 波起，每隔至少 3 波尝试以 55% 概率出现狗熊；场上最多一只，直接从随机完好塔旁出现，3～6 秒拆坏这座塔，有血条、敲击和摇晃动效；拆塔不随战斗倍速加速。点击狗熊或侧栏按钮进入丛林瞄准画布，熊左右移动，放大镜真实放大画面 2 倍，仅击中头部有效。移动指针瞄准、点击发射，也可用方向键和空格；命中 5 次随机一次性奖励 100～300 蜂蜜。瞄准时防线及维修暂停，没有倒计时，暂时返回保留命中数；修塔花原建造价的 20%，保留等级。

成长与收集：维修蜂累计修复基地 5 点解锁小帽子、20 点解锁工具箱（绘制在维修蜂旁）；首次击败每种虫子解锁图鉴，可展开查看弱点和小知识。记录保存在当前浏览器/插件的 localStorage，不跨设备同步，清除网站数据会重置。花粉减速中的虫子受到蜂胶炮额外 25% 伤害。

地图与传送门：开局在花园、树洞、池塘中选择，3 秒不选自动随机进入；树洞路线更长、虫子护甲 +2，池塘虫速降低 15%。第一对传送门在 6 个游戏秒后出现，持续 8～12 秒，消失后间隔 9～14 秒再出现。蓝色入口、紫色出口位于前后两个路径六边形，虫子跨过入口就跳到出口，最多跳过本对门一次。支持 1/2/3/4 倍速，暂停时所有战斗和门事件冻结。

维修：每 3 个游戏秒修复 1 点，历次派出首价为 4、6、8…蜂蜜；同次第 1、2、3…点按首价的 1、2、3…倍收费，修复完成时扣除。停止保留进度，再派出按新首价重新计算点序；暂停、缺蜜不会增加派出次数。重开游戏重置费用。受击后 3 秒内半速，缺蜜等待、满血自动结束；随暂停和倍速运行，波间有 13 秒休整。

蜂蜜反馈：击杀飘出「+N 蜂蜜」，顶部余额在 0.65 秒内平滑追上真实余额，配合收支数字和轻微弹跳。连续变化从当前显示值衔接；购买判断和扣款始终使用即时真实余额。系统要求减少动态效果时直接显示准确数字。

玩法：点击「开始防守」，选塔后点击非道路格建造，点击已有塔升级或出售。数字键 1–5 选塔，空格暂停，F 加速，N 提前下一波，Esc 取消选择。

生成提示词记录见 `ART_PROMPTS.md`。游戏保持原版中文界面，插件导航包含英文和简体中文资源。

验证：`node --test PluginExamples/hive-defense/tests/*.test.cjs`；浏览器动效与维修回归：`node PluginExamples/hive-defense/tests/feedback.browser.cjs`。测试复用游戏厅的 jsdom/Playwright 依赖。宿主插件验证使用 `ruby scripts/run_tests_fast.rb -only-testing:XeditTests/AgentPluginSystemTests`。
