VeilWriter Help

Write, browse, and edit with less ceremony.

VeilWriter is a lightweight macOS editor for opening a folder, moving through files quickly, and keeping common text workflows close at hand.

Getting started Editing Navigation Find and replace Markdown preview Command line Settings Troubleshooting

Getting started

  • Choose File > Open Folder to browse a project in the sidebar.
  • Choose File > Open File to open one file without selecting a folder.
  • In Finder, choose Open With > VeilWriter for text files, source files, or folders.
  • Use recent files and folders from the empty sidebar to return to previous work.
  • Use File > Open Containing Folder to reveal the active file in Finder.

Editing

  • Press Command-S to save the active file.
  • Press Command-Shift-S to save a copy with Save As.
  • Press Command-D to duplicate the current line.
  • Press Option-Up or Option-Down to move the current line.
  • Use Tab and Shift-Tab to indent or outdent selected lines.

Navigation

  • Press Command-P to open files quickly inside the selected folder.
  • Press Command-Shift-P to show the command palette, then use Up, Down, and Return to run the selected command.
  • Press Command-L to jump to a line in the active file.
  • Press Command-Shift-O to jump to a symbol in supported files.
  • Use Command-1 through Command-9, Command-Shift-[, and Command-Shift-] to switch tabs.
  • Press Command-Shift-T to reopen the most recently closed tab.

Find and replace

  • Press Command-F to search in the active editor.
  • Press Command-G or Command-Shift-G to move between matches.
  • Choose the active tab, all open tabs, or the selected folder as the find and replace scope.
  • Review highlighted matches before replacing text across a broader scope.

Markdown preview

  • Open a Markdown file, then choose View > Toggle Preview or press Command-Option-R.
  • The preview renders headings, paragraphs, quotes, lists, dividers, and fenced code blocks beside the editor.

Command line

  • Open VeilWriter > Settings, then install the veilwriter command from the Command Line Tool section. The command is installed in ~/.local/bin.
  • Run veilwriter . to open the current folder.
  • Run veilwriter file.md to open a specific file.

Settings

  • Open VeilWriter > Settings to adjust font, font size, line height, color style, line numbers, and current-line highlighting.
  • Enable save cleanup to trim trailing whitespace or ensure a final newline when saving.

Troubleshooting

A file will not open.
VeilWriter blocks binary files and asks for confirmation before loading files larger than 1 MB.
Changes appeared on disk outside the app.
Use the status bar reload action when VeilWriter reports that the active file changed externally.
Syntax highlighting looks stale.
Switch tabs or reopen the file. VeilWriter refreshes highlighting after file loads and tab activation.
